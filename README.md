# Koishi's Eye Sample

This is the sample that utilizes PlayStation Eye stuff.\
By the way, pressing START returns to XMB.

## How to compile?

You need a machine running Linux. WSL is supported.

1. Get [PS3DEV](https://github.com/ps3dev/ps3dev) and it's dependencies.
2. Compile the sample using `make pkg` command.
3. Install PKG in your PS3 system.

## Additional Notes
* The sample's code is partially AI-Assisted.
* All of the tests have been completed by a human on both emulator and real hardware.
